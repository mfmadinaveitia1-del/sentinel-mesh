# Sentinel Mesh

An interactive, **simulated** visualization of a defensive multi-agent security team
that assesses a company's own network for vulnerabilities within an authorized scope.

Agents (Scan Lead, Recon, CVE Intel, Risk Analyst, Validator, Remediation, Compliance)
are drawn as particle clouds; a crawler routes each message between them. Edit any
agent's brief, switch the orchestration topology (Supervisor / Pipeline / Debate) and
watch the handoffs and telemetry update live.

Educational prototype only: **no network is scanned and no model is called.** The plan,
token counts and issue counts are all simulated.

## Run locally
Open `index.html` in any modern browser — it is a single self-contained file.
